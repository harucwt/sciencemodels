# Modelos de ciencias en 3D

## Cambiar el título del menú

Edita la constante `MENU_TITLE` en `src/main.jsx` y ejecuta `npm run build` para actualizar la página.

## Añadir modelos

Agrega cada modelo a la lista `MODELS` en `src/main.jsx` y crea su página HTML en la raíz del proyecto. Las páginas base usan `modelo-base.css`; reemplaza el recuadro de ejemplo con el iframe del modelo 3D cuando esté disponible.
